2. **faithfulness** — Does the artwork/theme match the spec's theme, gender, tags,

3. **constraints** — Does the prompt include a NEGATIVE CONSTRAINTS block covering

   describing anything banned (real logos, explicit anatomy, medical claims)?
4. **template** — Does it follow the skeleton order (MAIN ARTWORK → BRANDING →

5. **grounding** — Is the described style consistent with the reference images'
   genre (lurid glossy single-serve blister card), rather than drifting toward a
   clean pharmacy/medical look?

`verdict` = `pass` only if completeness AND constraints pass and no other
criterion is a hard miss. Otherwise `revise`.
