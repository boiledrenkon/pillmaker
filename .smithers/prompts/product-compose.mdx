## How to fill each copy slot (subtitle, taglines, copy lines, bottom slogan, capsule, packaging style, hero scene)

Each slot is in one of three states. Decide per field:

1. **Blank / null in the spec → INVENT it** from `theme` + `name` + `gender`. This
   is the main job. Author a vivid hero scene and confident parody copy that fit
   the theme. Do not leave a slot empty just because the spec didn't supply it.
2. **Provided as a plain value → WEIGHTED SEED.** Honor its intent and keep its
   gist, but you may polish wording, casing, or length to fit the house style and
   theme. It is a strong steer, not sacred.
3. **Listed in VERBATIM (below) → reproduce EXACTLY.** Any subtitle / tagline /
   copy line shown in the VERBATIM list must appear in the prompt character-for-
   character as written (same spelling, same caps) — never paraphrase, add to, or
   drop it. These are the strings that must render legibly on the package. The
   spec is already clean; there is no marker to strip — just reproduce them.

## House style for the hero artwork (MAIN ARTWORK)

By genre convention these packs **always** feature an attractive, **visibly pleased / blissful / admiring partner figure** reacting to the product — it's a core selling point. Include one by default, matched to the audience:

- **male** → a beautiful woman, delighted / swooning / blissfully pleased.
- **female** → a handsome, adoring/swooning man.
- **couples** → both partners, mutually enraptured.

Make her/him **tasteful and suggestively sensual, never explicit** — expression of pleasure/admiration, flattering figure, alluring but **fully clothed** in theme-appropriate attire; nothing that violates the NEGATIVE CONSTRAINTS (no nudity, no explicit anatomy, no pornographic depiction). Weave the figure naturally into the themed hero scene alongside the main character. Only omit if the spec's extra instructions explicitly say to.

## ART DIRECTION — derive it from the theme, never default

What stays constant across the product line (the identity): a small-format
novelty "enhancement" product as sold at a convenience-store counter — a huge
title, lurid confident parody copy, and the dose itself visible/showcased in the
packaging. **Everything else is yours to art-direct per theme:**

- **Format** — the classic is a single capsule under clear blister plastic (the
  industry's main trend), but the genre also runs on chewables/gummies, "honey
  pack" sachets, liquid shots, and 2-dose blisters. If the spec provides a
  `format`, honor it; otherwise default to the capsule blister UNLESS the theme
  clearly calls for something better (a bee/nectar theme wants a honey sachet, a
  candy theme wants gummies). Describe the chosen format concretely in THE DOSE.
- **Palette** — pick 2–4 dominant hues that belong to the theme's world (deep-sea
  → bioluminescent teal / abyss black; cowboy → worn leather brown / sunset
  orange / denim blue). Name them concretely in MAIN ARTWORK, THE DOSE, and
  PACKAGING STYLE.
- **Typography** — choose a lettering treatment the theme's world would use:
  weathered saloon woodtype, neon sci-fi chrome, gothic blackletter, bubbly 90s
  toy caps, stenciled military block… Embossed chrome-and-gold is ONE classic
  option — reach for it when the theme calls for bling, not by habit.
- **Finish / materials** — foil stamp, holographic sheen, matte kraft, greasy
  clamshell plastic, airbrushed gradient, cheap risograph — whatever the theme's
  world would actually print this pack in.
- **Composition** — vary the staging pack to pack: hero mid-action with the
  partner reacting, the partner front-and-center swooning, a before/after gag, a
  crowd of admirers. Don't fall back on one layout by default.

Two packs from different themes should read as siblings from the same shelf —
never as the same pack recolored.

## House style for invented copy

Punny, lurid, confident parody in the voice of cheap gas-station blister-card
"male enhancement" packaging — double-entendres tied to the theme, over-the-top
superlatives, invented dosages / "clinical-grade" / fake certifications, ALL-CAPS
hero phrases. Keep it clearly fictional novelty parody. When inventing, produce:
a subtitle, a main tagline, a secondary tagline, 2–3 supporting copy lines, an
optional bottom slogan, a capsule look, and a packaging aesthetic — all themed.

**Keep on-pack text LEAN.** The image generator must render every word legibly,
and it garbles dense or tiny text. So favor FEW, SHORT, punchy lines over a wall
of copy: the NAME, one subtitle, one main tagline, at most 2–3 short supporting
lines (≤ ~5 words each), and an optional short bottom slogan. Make the hero
NAME + main tagline the star; do not crowd the pack with long sentences or many
small lines. Brevity here directly improves how cleanly the package renders.

**Express color / visual direction POSITIVELY.** The image generator renders what
you NAME and largely ignores "don't" / "avoid" phrasing. When a palette or look
matters, state the concrete hues you DO want, up front in MAIN ARTWORK and CAPSULE
(e.g. "capsule: marbled swirl of teal, cobalt, magenta, crimson, amber, emerald —
a painter's-palette blend"). Never steer by forbidding a look, and never spell out
a rainbow / ROYGBIV sequence you are trying to avoid — naming it only cues it.
Reserve NEGATIVE CONSTRAINTS for true content prohibitions, not aesthetic nudges.
